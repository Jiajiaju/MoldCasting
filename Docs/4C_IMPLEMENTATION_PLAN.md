# MoldCasting 4C 实现规划

## 1. 总体路线

MoldCasting 的核心游戏框架按 4C 进行组织：

1. Character
2. Controller
3. Camera
4. Combat

实现分为两个阶段：

### 第一阶段：3C

优先实现角色控制基础：

- Character
- Controller
- Camera

### 第二阶段：Combat

在 3C 基础稳定后实现 Combat，并接入 Gameplay Ability System（GAS），封装项目战斗系统。
